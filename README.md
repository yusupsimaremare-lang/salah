Character Manager merupakan project pemrograman Java yang dibuat untuk memenuhi tugas TP3 AP3 Belajar Praktik. Project ini menerapkan konsep Object-Oriented Programming (OOP), seperti class, object, constructor, encapsulation, getter, setter, dan enum.

Project ini memiliki tiga jenis karakter utama, yaitu Warrior, Mage, dan Archer. Selain itu, terdapat fitur tambahan berupa atribut mana, validasi mana, method isAlive(), serta fitur level up untuk meningkatkan statistik karakter.
1. Membuat karakter menggunakan dua constructor.
2. Menggunakan enum CharacterType untuk menentukan jenis karakter.
3. Menggunakan encapsulation dengan atribut private.
4. Menyediakan getter dan setter.
5. Menghitung ulang HP dan attack power ketika level berubah.
6. Menambahkan atribut mana dengan validasi nilai negatif.
7. Menambahkan method isAlive() untuk memeriksa kondisi karakter.
8. Menampilkan informasi karakter menggunakan toString().
